# Dashboard de RICs

## Publicação no GitHub Pages
1. Envie `index.html`, `style.css`, `app.js` e `modelo_base_RICs.csv` para o repositório.
2. Abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/root`.
5. Abra o endereço publicado e use **Atualizar dados** para carregar a base.

A base fica salva localmente no navegador do usuário.
